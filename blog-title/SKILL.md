# blog-title — 네이버 블로그 제목 5개 생성

네이버 원본 제목의 실제 컨벤션을 근거로, 주제 한 줄 → 제목 후보 5개를 뽑습니다.

## 전제

- **제목의 정본(SSOT)은 무조건 네이버 원본.** 대괄호 표기·구분자·화수 전부 네이버 실제 제목에서 확정한다(아래 0단계). 티스토리 정리본은 서식이 훼손돼 있으니(대괄호 안 공백 제거 `[포켓몬 GO]`→`[포켓몬GO]`, 구분자 `:`→`/`, 뒤에 ` | 정리본`) 근거로 쓰지 않는다.
- **로컬 코퍼스(`./.claude/blog-corpus`)는 쓰지 않는다. 존재 확인도 하지 않는다.** 항상 네이버 API를 그 자리에서 호출해 최신 상태로 학습한다. (2026-08-19 사용자 지시: 코퍼스 뒤지지 말고 무조건 온라인에서 최신 갱신해서 쓸 것.)
- 카테고리가 애매하면 추측하지 말고 사용자에게 물어볼 것.

### 0. 네이버 원본으로 형식·화수 확정 (필수)

같은 카테고리의 **네이버 실제 제목**을 직접 열거해 (a) 대괄호 표기, (b) 구분자, (c) 최신 화수를 확정한다:
```bash
curl -s -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15" \
  -H "Referer: https://m.blog.naver.com/op5321" \
  "https://m.blog.naver.com/api/blogs/op5321/post-list?categoryNo=0&itemCount=30&page=1" \
  | python3 -c "import sys,json,html; d=json.load(sys.stdin); [print(p.get('logNo'), html.unescape(p.get('titleWithInspectMessage',''))) for p in d.get('result',{}).get('items',[])]"
```
- 관측된 네이버 제목 형식: **`[카테고리 ] N. 본문 : 서브`** — 대괄호 안 **공백 유지**(`[포켓몬 GO]`, `[젤다 왕눈]`), 주 구분자 **` : `(콜론)**, 서브 여럿이면 ` / `도 섞임. `| 정리본`은 티스토리 전용이니 **절대 붙이지 말 것**.
- 번호 시리즈면 **화수는 네이버 최신 제목의 최대 N +1**(기억·코퍼스 아님, [[feedback_episode_number_from_rss]] 원리). 티스토리는 네이버보다 늦으니 반드시 위 API로 확인.

## 입력

```
/blog-title "<주제>" [--category "<카테고리명>"] [--n 5]
```

예:
- `/blog-title "2026 SMKX 서울 키보드 박람회 방문기" --category "팝업/굿즈/오프"`
- `/blog-title "포코피아 47화 라프라스 전설 의뢰" --category "포코피아"`

`--category` 생략 시: 주제 키워드와 네이버 카테고리 목록·기존 제목을 매칭해 가장 적합한 카테고리를 추정한 뒤, **추정 결과를 사용자에게 1줄로 알리고** 진행. 추정 신뢰도가 낮으면 (매칭 점수 낮음) 사용자에게 카테고리를 되묻기.

## 절차

### 1. 패턴 추출 (네이버 실시간 열거)

카테고리 번호를 모르면 먼저 카테고리 목록을 뽑는다:
```bash
curl -s -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15" \
  -H "Referer: https://m.blog.naver.com/op5321" \
  "https://m.blog.naver.com/api/blogs/op5321/category-list"
```
그다음 해당 카테고리의 실제 제목을 열거한다(0단계 post-list API에 `categoryNo=<N>` 지정).

열거된 실제 제목에서 다음을 읽어 컨벤션 모델링:
- `[]` 태그 전체: 그 카테고리에서 실제로 사용된 대괄호 태그와 빈도
- 트레일링 토큰 분포 (예: 팝업 5, 굿즈 2, 방문후기 1) → 어떤 "형태" 어휘가 정착되어 있는지
- 리딩 토큰 분포 → IP/브랜드 표기 방식
- `]` 뒤 본문 패턴 (구분자, 길이감, 날짜·차수 포함 여부)

### 2. 컨벤션 진단

추출 결과로부터 **이 카테고리에서 관측된 규칙**을 명시적으로 정리. 예:
- 태그 형식: `[IP/브랜드 + 형태]` 2단어 조합 (단일어 케이스도 N건 존재)
- 형태 어휘 후보: 가장 자주 쓰이는 trailing 토큰 N개 중 주제에 맞는 것 선택
- 본문 구조: `방문기 / 부제 / 날짜` 슬래시 구분 (관측된 경우만)

이 진단을 출력에 1~2줄로 짧게 표시 (사용자가 왜 그 패턴을 따랐는지 검증할 수 있게).

### 3. 후보 5개 생성

각 후보는 다음을 만족:
- **태그**: 카테고리에서 관측된 `[IP 형태]` 패턴을 따른다. 새 형태 어휘를 도입할 땐 기존 어휘 중에 적합한 게 없을 때만, 그리고 길이 10자 이내로.
- **본문 제목**: 주제 안에 있는 **공식 명칭을 그대로** 사용 (왜곡·임의 약어화 금지). 예: "서울 키보드 박람회"는 줄이지 말 것.
- **부제**: 카테고리에서 관측된 패턴을 따라 슬래시 `/`로 부제·날짜 구성. 부제는 본문 단어 단순 반복이 아니라 추가 정보(서브토픽, 날짜, 인상평 등).
- **태그-본문 단어 중복**은 사용자 기존 글에서 이미 허용됨 (예: `[명조 굿즈] 명조빵`). 일부 중복은 OK, 같은 단어 3회 이상 반복은 피할 것.

후보 5개는 서로 차별성을 가져야 함 (전부 똑같은 부제 패턴이면 무의미). 권장 다양성:
1. 가장 안전한 컨벤션 그대로 (추천)
2. 부제 강화형 (인상·핵심 키워드 부각)
3. 날짜 포함형 (관측되는 경우)
4. 태그 약어/풀네임 변형형 (예: `[SMKX 박람회]` vs `[키보드 박람회]`)
5. 부제 톤 변형형 (감정적·궁금증 유발)

### 4. 출력 (필수 템플릿)

마크다운으로 다음 형식 정확히 출력:

```
## 카테고리: <카테고리명> (관측 N개 글, 네이버 기준)

**관측 컨벤션**: `[<IP> ] N. 본문 : 부제` (대괄호 안 공백 유지, 구분자는 0단계에서 확정한 네이버 실제 구분자 — 대개 ` : ` 콜론)

**제목 후보 5개**:

1. **[추천]** [태그] N. 본문 : 부제
2. [태그] N. 본문 : 부제
3. [태그] N. 본문 : 부제 / 2026.MM
4. [태그variant] N. 본문 : 부제
5. [태그] N. 본문 : 부제 (톤 변형)

**사유 한 줄씩**:
1. — 왜 이게 안전한지
2. — ...
3. — ...
4. — ...
5. — ...
```

### 5. 자체 검수

다음을 출력 전에 확인하고, 위반 시 재작성:

- [ ] 이모지 0개 (`grep -P '[\x{1F300}-\x{1FAFF}\x{2600}-\x{27BF}]'`로 점검 가능)
- [ ] 주제 안의 공식 명칭이 후보 5개 중 최소 3개에서 변형 없이 보존됨
- [ ] 모든 후보가 카테고리에서 관측된 형태 어휘 또는 그 자연스러운 확장만 사용
- [ ] 태그 길이 12자(공백 포함) 이하

## 하드룰

- **제목 형식·화수는 무조건 네이버 원본 기준**(0단계). 대괄호 안 공백 유지(`[포켓몬 GO]`), 구분자 콜론(` : `), `| 정리본` 금지. 티스토리·코퍼스가 네이버와 다르면 네이버를 따른다.
- **이모지 금지**. 한 글자도 쓰지 말 것.
- **행사·브랜드명 왜곡 금지**. SMKX의 "서울 키보드 박람회"를 임의로 "키보드 쇼"로 줄이거나 표기를 바꾸지 말 것. 약어가 필요하면 (1) 공식 약어, (2) 영문 원어 중에서만 선택.
- **카테고리는 네이버 category-list API에 실제 존재하는 것만**. 새 카테고리 만들지 말 것.
- 카테고리 추정 시 신뢰도가 낮으면 후보 출력 전에 사용자에게 되물을 것.
- **로컬 코퍼스(blog-corpus) 사용 금지.** 패턴·화수·태그의 근거는 전부 네이버 API 실시간 호출이다. 존재 확인조차 하지 않는다.

## 기존 글 리네이밍 모드

사용자가 "기존 글 제목도 다시 뽑아줘"라고 하면:
- 네이버에서 열거한 실제 제목들에서 컨벤션을 벗어난 태그(예: 단일어인데 같은 카테고리 다수가 2단어인 경우)를 식별
- 해당 글들에 대해서만 후보 1~2개씩 제안
- **일괄 변경 비추천 안내**: 네이버는 제목 변경 시 검색 캐시 재인덱싱이 필요해 일시적 노출 흔들림 발생. 트래픽 적은 옛 글 위주로 점진 정비를 권장.
