# english-study 스킬 설계

작성일: 2026-07-06
상태: 사용자 승인 대기

## 목적

박기린(op5321)의 영어 학습 루틴을 스킬화한다. 레벨: 읽기 중급, 듣기 초급, 말하기 완전 초급. 세션당 10~20분, 출근길·틈새 시간에 수시 실행.

핵심 루프: 게임/자유 토픽 뉴스 큐레이션 → 쉬운 영어 리라이팅 제시 → 사용자가 영어 소감 작성 → 3단계 교정 → 단어·숙어 Notion 저장 → 세션 말미 Leitner 복습.

## 스킬 정의

- 이름: `english-study` (디렉토리 `english-study/`, SKILL.md + `scripts/fetch_news.py`)
- 트리거:
  - 전체 세션 — `/english-study`, "영어 공부하자", "오늘의 영어 뉴스", "영어 뉴스 브리핑"
  - 복습만 모드 — "복습만 해줘", "단어 복습"
- 하드룰:
  - 이모지 금지 (리포 공통)
  - 게임명·회사명 등 고유명사 왜곡 금지 (리포 공통)
  - Notion 실패 시 무단 진행 금지 — MCP 무응답, 좌표 404, 저장 결과 이상(한글 깨짐 등) 시 임의로 우회·대체·재생성하지 않는다. 상황 보고 후 사용자 허락을 받고 진행. `notion-search` 재탐색까지는 허용하되, 찾은 좌표로 실제 쓰기 전에 확인받는다. 저장 실패 세션은 저장 대기 목록을 대화에 남기고 지시를 기다린다.

## 전체 세션 흐름 (약 15~20분)

1. **난이도 확인**: Notion 방법론 페이지에서 현재 리라이팅 난이도 단계를 읽는다.
2. **뉴스 수집**: `fetch_news.py` 실행 → 후보 목록에서 게임 2건 + 자유 토픽 1건 선정 (화제성·재미 기준). 사용자가 "오늘은 1건만" 등으로 세션 중 분량 조절 가능. 최근 다룬 뉴스와의 중복은 단어장 DB "출처" 필드로 근사 확인, 겹치면 다음 후보.
3. **건마다 반복** (건당 4~5분):
   1. 현재 난이도 단계에 맞춰 리라이팅 제시. 실제 회화에서 쓰이는 자연스러운 문장으로 쓰되 교과서체 금지. 배울 만한 표현 2~3개는 굵게 + 짧은 한국어 힌트. 원문 링크 병기.
   2. 사용자가 영어로 소감 1~3문장 작성 (짧아도 됨).
   3. 3단계 피드백: ① 뜻이 통했는지 ② 문법·표현 교정 ③ 원어민이라면 이렇게 말한다 버전. 교정에서 나온 좋은 표현도 저장 후보에 추가.
   4. 저장할 단어·숙어 2~4개 확정 (Claude 제안, 사용자 가감).
4. **Notion 저장**: 단어를 한 건씩 순차 생성 (batch 금지 — 리포 관례). 저장 직후 fetch로 한글 리터럴 깨짐 재검증, 깨졌으면 즉시 교정.
5. **복습**: 아래 복습 알고리즘 실행. "복습만 모드"는 이 단계만 단독 실행.

## 리라이팅 난이도 4단계

1. 전면 리라이팅 (B1, 회화체 쉬운 문장) — 시작 단계
2. 부분 리라이팅 (어려운 문장만 풀어쓰고 원문 표현을 점점 살림)
3. 원문 그대로 + 어려운 단어에만 괄호 힌트
4. 원문 그대로 (힌트 없음)

승급: 자동 상향 금지. 신호(소감에서 내용 오해 없음, 복습 정답률 높음, "요즘 쉽다" 체감 발언)가 쌓이면 Claude가 상향을 제안하고 동의 시 적용. 오해가 잦으면 하향 제안. 특정 뉴스만 유난히 어려우면 그 건만 일시적으로 쉽게 쓰는 유연성 유지. 현재 단계는 Notion 방법론 페이지에 기록 (기기독립 상태 저장).

## 뉴스 수집

`english-study/scripts/fetch_news.py`:

- Reddit 공개 JSON API + 커스텀 UA로 조회: r/games (게임 뉴스), r/gaming (게임 소식·재미), r/popular (자유 토픽), 각 top of day
- 출력: 후보별 제목·요약·점수·댓글수·URL의 JSON

폴백 체인 (네이버 수집 관례 — WebFetch가 막히는 사이트는 curl + 브라우저 UA로 직접 — 적용):

1. 1차: `fetch_news.py` (urllib/requests + 커스텀 UA)
2. 2차: `curl` + 브라우저 UA로 `old.reddit.com/r/<sub>/top.json` 직접 조회. 엔드포인트와 UA 문자열을 SKILL.md에 명기해 어느 세션이든 재현 가능하게 한다.
3. 최후: 둘 다 막힌 날만 WebSearch로 대체하고, 다음 세션에서 스크립트 점검

## Notion 단어장 DB

개인 워크스페이스(pos000830)에 새 전용 DB "영어 단어장" 생성. 좌표(페이지·데이터소스 ID)는 생성 후 SKILL.md에 고정 기재.

| 속성 | 타입 | 내용 |
|---|---|---|
| 표현 | title | 단어/숙어 원형 |
| 뜻 | text | 한국어 뜻 |
| 예문 | text | 그 표현이 나온 뉴스/교정의 실제 문장 |
| 유형 | select | 단어 / 숙어·구동사 / 회화 표현 |
| 출처 | text | 뉴스 제목 또는 "내 소감 교정" |
| 등록일 | date | 저장한 날 |
| 복습 단계 | select | 0~5 |
| 다음 복습일 | date | 복습 대상 조회 기준 |
| 상태 | select | 학습 중 / 졸업 |

**방법론 페이지** (DB 상단 1개): Leitner 간격표, 퀴즈 형식 규칙, 세션 절차 요약, 현재 리라이팅 난이도 단계.

이중화 원칙: SKILL.md(상세본, git) + Notion 방법론 페이지(요약본, 기기독립). 규칙 변경 시 둘을 같이 갱신하는 것을 스킬 절차에 포함. 목적 — 리포가 없는 컴퓨터나 모바일에서도 "영어 단어장 DB 보고 복습시켜줘"로 방법론·데이터 모두 복원 가능.

## 복습 알고리즘 (Leitner)

- 간격표: 단계 1 = 1일, 단계 2 = 3일, 단계 3 = 7일, 단계 4 = 14일, 단계 5 = 30일
- 신규 저장 단어: 단계 0, 다음 복습일 = 내일 (첫 복습은 저장 다음날)
- 대상: 다음 복습일 ≤ 오늘, 오래된 것부터 최대 10개
- 퀴즈 형식은 복습 단계별 자동 배정:
  - 단계 0~1: 한→영 회상
  - 단계 2~3: 문장 빈칸 (원래 나온 뉴스와 비슷한 문맥의 문장)
  - 단계 4~5: 직접 문장 만들기 (사용자 영작 → Claude 교정)
- 맞히면 단계 +1, 다음 복습일 = 오늘 + 새 단계의 간격. 틀리면 단계 0, 다음 복습일 = 내일
- 단계 5 복습(30일 간격)까지 맞히면 상태 = 졸업, 복습 대상 제외
- 날짜 계산은 기억이 아니라 `currentDate` 기준 python으로 계산 (리포 컨벤션)
