# naver-photo-censor — 검열/미검열본 발행 (노출 부위 회색 박스)

네이버가 "살 노출 과다"로 검색 노출을 막는 글(수영복 일러스트 등)에 대해 **검열본(공개)** 과
**미검열본(이웃전용 등)** 두 벌을 운용하는 스킬. 검열은 이미지를 부위별 회색 박스(150,150,150)로
가리고, 발행은 [[naver-to-naver]] `migrate.py --local-images`가 **파일명 1:1 스왑**으로 처리한다
(원본 폴더=미검열본, 검열본 폴더=검열본 — 네이버가 업로드 원본 파일명을 URL에 보존하는 트릭).
2026-07-13 몬길9(29장, GIF 4 포함)로 검열 실전 검증 — 축소 이미지로 눈대중 판독했을 때 박스가
얼굴·배를 덮고 정작 가슴골이 노출되는 사고가 반복됐다. 아래 절차가 그 사고들의 재발 방지책이다.

## 두 방향 발행 (요약)
- **미검열본 발행** (검열본이 이미 공개된 글 → 노검열 이웃전용): 검열 단계 없이 바로
  `migrate.py <검열본글URL> --local-images <원본폴더>`. 각 사진이 파일명 매칭으로 원본과 교체됨.
- **검열본 발행**: 아래 1~3단계로 검열본 폴더를 만든 뒤 `migrate.py <소스URL> --local-images <검열본폴더>`.
- **공통 검수**: dry-run의 `스왑 N / 폴백 M` + `누락 0`을 먼저 확인. 폴백(폴더에 없어 네이버에서 그대로
  받은 것)이 스티커/밈 등 **비사진**만인지 반드시 확인 — 검열 대상 사진이 폴백으로 새면 안 된다.

## 가림 기준 (사용자 지시 — 절대 준수)
- **가리는 것**: 파인 가슴골(깊은 클리비지·언더붑), 짧은 하의/팬티 부위, 노출 엉덩이.
- **가리지 않는 것**: 얼굴, 배꼽/허리, 팔다리, 어깨, 수영복으로 덮인 부분. 전신 덮기 금지.
- 박스는 부위별 소형 여러 개(사진당 1~4개)가 정답. 캐릭터가 작은 배너/전투샷은 살짝 크게 잡아도 됨.

## 워크플로 (전부 실측 검증된 순서)

### 0. 대상 목록
이미지 경로 목록 파일(1줄 1경로, 줄 번호 = 이미지 번호)을 만든다. naver-to-naver 파이프라인이면
`migrate.py`의 청크 순서에서 img 경로만 뽑으면 된다(캐시 `~/.cache/naver-to-naver/` 파일들).

### 1. 좌표 판독 — 격자 싱글로만
```bash
python3 scripts/make_singles.py --order img_order.txt --nums 5,13,24 --grid --out /tmp/grids
```
- 920px + 0.05 격자(0.1마다 라벨). **한 장씩 Read로 정독**해 부위의 0~1 비율 좌표를 판독한다.
- **축소 콘택트시트·2x2 격자 판독 금지** — 박스가 몸에 붙어 보여도 실물에선 빗나간다(반복 실사고:
  #5 물 위, #44 UI 위, #50 계단 위에 박스가 갔다).

### 2. 스펙 작성 + 가리기
```bash
# spec JSON: {"이미지번호": [[x1,y1,x2,y2], ...]}  (0~1 비율)
python3 scripts/censor_boxes.py --order img_order.txt --spec boxes.json
```
- 원본은 캐시 `orig/`에 자동 백업 — 재실행은 항상 원본에서 다시 그리므로 박스 조정이 안전하다.
- GIF는 전 프레임 적용(재인코딩으로 용량이 커질 수 있음). 움직임 여유분을 박스에 더한다.
- 스티커(storep) 등 비대상은 스펙에서 빼면 원본 유지.

### 3. 전 장 실물 검수 — 통과 전 진행 금지 (사용자 지시)
```bash
python3 scripts/make_singles.py --order img_order.txt --nums 5,13,24 --out /tmp/verify
```
- 가린 결과를 720px 싱글로 **한 장씩 Read로 재검수**: (a) 박스가 부위에 정확히 안착했는가,
  (b) 가슴골·하의가 박스 밖으로 새지 않는가, (c) 얼굴·배를 불필요하게 덮지 않았는가.
- 하나라도 어긋나면 1~2단계로 돌아가 그 장만 다시 잡는다(원본 재작업이라 안전).
- **전 장 통과를 확인한 뒤에만** 다음 단계(마이그레이션/업로드)로 진행한다.

### 4. 후속 (발행)
- 검열본 발행: `/naver-to-naver` `migrate.py <소스URL> --local-images <검열본폴더>` (파일명 1:1 스왑).
  레거시 `--censored`(URL-해시 캐시)도 남아있으나 폴더를 명시하는 `--local-images`가 더 안전하다.
- 미검열본 발행: `migrate.py <검열본글URL> --local-images <원본폴더>`.
- 발행은 사용자가 직접(무인 발행 금지). 이웃전용 등 공개범위는 발행 다이얼로그에서 사용자가 지정.
- 색인 회복 확인은 `/naver-search-check`.

## 함정
- PIL 좌표는 (x1,y1,x2,y2) 픽셀 — 스크립트가 비율을 곱해준다. 비율은 항상 0~1.
- 큰 GIF(10MB급)는 프레임 처리 수십 초 — 정상.
- 얼굴 인식 기반 자동화(face-anonymizer)는 '얼굴'용이다 — 몸 부위는 수동 판독이 정답.

## 의존
- `python3` + Pillow, macOS 불필요(순수 이미지 처리)
- `scripts/censor_boxes.py` — 스펙 적용(백업·GIF 전 프레임)
- `scripts/make_singles.py` — 격자 판독용/검수용 싱글 렌더러

## 관련
- `/naver-to-naver` — 재발행 파이프라인(가려진 캐시 사용)
- `/naver-search-check` — 서치 블락 진단·회복 확인
- `/face-anonymizer` — 얼굴 전용 가리기(회색 원)
