# 앱 내부명과 표기 매핑

스펙 9.4절의 정본입니다. 삼성 스크린샷 파일명에 박히는 앱 내부명을 사용자가 실제로
쓰는 표기로 옮깁니다. 임의 음차와 직역을 금지합니다.

우선순위는 블로그 글 제목 > 애플 사진 앱 앨범 이름 > 나무위키 표제어 > 사용자 확인입니다.

`Heartopia`는 앱 내부명만으로는 알 수 없는 사례입니다. 나무위키를 거쳐야 블로그의
`[두근두근타운]` 32편과 같은 게임임이 드러납니다.

## 계층 키워드

포켓몬 계열은 사진 앱이 `포켓몬스터` 하나인데 블로그는 다섯 갈래입니다. 둘 다 살립니다.

| 잎 | 계층 |
|---|---|
| 포켓몬 GO | 포켓몬\|포켓몬 GO |
| 포켓몬 홈 | 포켓몬\|포켓몬 홈 |
| 포켓몬 ZA | 포켓몬\|포켓몬 ZA |
| 포챔스 | 포켓몬\|포챔스 |
| 포켓몬 카드 게임 Pocket | 포켓몬\|포켓몬 카드 게임 Pocket |
| 포켓몬 파레리그 | 포켓몬\|포켓몬 파레리그 |
| 명조 | 게임\|명조 |
| 원신 | 게임\|원신 |
| 붕스 | 게임\|붕스 |
| ZZZ | 게임\|ZZZ |
| 니케 | 게임\|니케 |
| 소녀전선2 | 게임\|소녀전선2 |
| 두근두근타운 | 게임\|두근두근타운 |
| 모동숲 | 게임\|모동숲 |

`dc:Subject`에는 잎만 넣고 `lr:HierarchicalSubject`에 계층을 넣습니다. 계층을 읽는
프로그램은 상위로 묶어 보고, 모르는 프로그램은 잎만 평평한 태그로 읽습니다.
