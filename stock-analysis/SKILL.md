# stock-analysis — 종목 실시간 현황 수집 및 정리

## 원칙

- **조회 시점 기준 최신 정보**만 사용. 오래된 캐시나 기억에 의존하지 않는다.
- **공식 출처 우선**: DART 공시 → 회사 IR → 증권사 리포트 → 뉴스 순으로 신뢰도를 부여한다.
- 잠정실적(잠정)과 확정실적(분기/반기/사업보고서)을 반드시 구분해 표기한다. 혼동하면 분석이 틀린다.
- 출처 없는 수치는 절대 쓰지 않는다. 추측이면 추측이라고 명시한다.

---

## 입력

```
/stock-analysis "<종목명 또는 코드>" [--context "보유 수량, 평균단가 등 추가 맥락"]
```

예: `/stock-analysis "펄어비스" --context "58800원에 150주 보유"`

---

## 수집 절차

### Step 1. 실시간 주가 — 브라우저 직접 조회

토스증권 페이지를 브라우저로 열어 현재가를 직접 확인한다. 검색 결과 스니펫은 지연이 있으므로 보조 참고만.

```
https://www.tossinvest.com/stocks/A{종목코드}/order
```

페이지 타이틀에서 현재가·등락률을 추출한다.  
타이틀 형식: `{현재가}원 {등락률}% | {종목명}`

백업: 다음금융 `https://m.finance.daum.net/quotes/A{종목코드}/home`

수집 항목:
- 현재가, 전일 대비 등락률
- 거래량
- 52주 최고/최저가

---

### Step 2. 공식 공시 — DART 전자공시시스템

**반드시 DART를 직접 조회**한다. 뉴스 기사의 실적 수치는 DART 공시가 원본인지 확인 후 사용한다.

```
https://dart.fss.or.kr/dsab001/search.ax?textCrpNm={종목명}&autoSearch=Y
```

확인 항목 (우선순위 순):
1. **분기보고서 / 반기보고서 / 사업보고서** — 확정 실적. 가장 신뢰도 높음
2. **연결재무제표기준영업(잠정)실적** — 잠정 수치. 향후 확정 보고서와 다를 수 있음
3. **영업실적등에대한전망(공정공시)** — 회사 가이던스
4. **기업설명회(IR)개최** — IR 발표 자료 존재 여부 확인

**잠정 vs 확정 판단 기준:**
- 공시 목록에 해당 분기의 `분기보고서`가 있으면 확정
- `잠정실적` 공시만 있고 `분기보고서`가 없으면 잠정
- 분기 종료 후 45일이 제출 기한 (예: 1Q = 3/31 종료 → 5/15 기한)
- 항상 "이 수치는 잠정/확정" 여부를 명시할 것

---

### Step 3. 최신 뉴스 — WebSearch 복수 쿼리

단일 쿼리에 의존하지 않는다. 아래 쿼리를 병렬로 실행한다:

```
"{종목명} 주가 {현재 연도} {현재 월}"
"{종목명} 실적 {현재 연도} {현재 월}"
"{종목명} 애널리스트 목표주가 {현재 연도}"
```

검색 결과에서:
- 기사 날짜를 반드시 확인. **오늘 날짜로부터 2주 이상 지난 기사는 "구버전" 표시**
- 증권사 리포트 링크가 있으면 별도 표기
- 공매도·수급 관련 최신 동향 포함

---


## 주의사항

- 투자 판단(매수/매도/보유 여부)은 제시하지 않는다. 데이터와 팩트만 정리하고, 의견이 필요하면 "내 관점"임을 명시한 후 짧게 덧붙인다. 단, 사용자가 "너라면 어떻게 했을 것 같아", "인간이라면" 등 가상 시나리오를 명시적으로 요청하면 **"가상 시나리오 (투자 조언 아님)"** 을 전제로 짧게 답한다.
- DART 접근이 막히면 반드시 사용자에게 알리고, dart.fss.or.kr에서 직접 확인을 요청한다.
- 토스증권 브라우저 접근이 막히면 WebSearch로 보완하되, 검색 스니펫 가격은 지연 가능성을 명시한다.
